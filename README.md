Notasyon yazımı için alıştırma kağıdı
-------------------------------------

notasyon_alistirma_bos.svg: boş tahta için SVG dosyası (inkscape)
notasyon_alistirma_bos.pdf: boş tahta için PDF dosyası

notasyon_alistirma_izli.svg: izli harfler olan tahta, SVG.
notasyon_alistirma_izli.pdf: izli harfler olan tahta, PDF.

denden.py: izli harfleri eklemek için kullandığım Python script'i.

Tahta kenarındaki harfleri "Comic Sans MS" (Microsoft) ile, harf izlerini de "Trace" (Kids Fonts; https://www.fontspace.com/trace-font-f3625 adresinden indirilebilir) ile yazdım.
